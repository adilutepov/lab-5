Open-Source Testing: GnuPG (Gpg4win / PowerShell) Practical Walkthrough

Covers Item 3 of Lab #5 requirements: testing open-source cryptographic software on Windows (PowerShell / CMD). Demonstrates OpenPGP keypair generation, hybrid file encryption, and detached digital signature verification.

Windows: gpg.exe (PowerShell)
0

Step 0: GnuPG на Windows (Winget НЕ нужен!)

На твоем компьютере GnuPG уже установлен вместе с Git for Windows! Выбери удобный вариант запуска:

# Вариант А: В PowerShell выполни один раз этот алиас:
Set-Alias gpg "C:\Program Files\Git\usr\bin\gpg.exe"
# После этого команда gpg будет работать в окне PowerShell напрямую!
# Вариант Б: Открой "Git Bash" (Пуск -> Git Bash):
gpg --version
# В терминале Git Bash утилита gpg уже прописана в путях по умолчанию.
# Вариант В: Скачать официальный установщик с графическим интерфейсом Kleopatra:
https://www.gpg4win.org (прямой .exe файл)
1

Step 1: OpenPGP Keypair Generation (PowerShell / Git Bash)

Launch interactive key generator in PowerShell or Git Bash:

PS C:\Users\Admin> gpg --full-generate-key
# Interactive choices: # 1. Please select what kind of key you want: (9) ECC (sign and encrypt) # 2. Please select which elliptic curve you want: (1) Curve 25519 # 3. Key is valid for? (0) does not expire # 4. Real name: Lab Tester # 5. Email address: tester@crypto.edu # 6. Enter PIN/Passphrase in Windows popup window
2

Step 2: Create Test File & Hybrid Encryption (PowerShell)

Create document in PowerShell and encrypt it with the recipient's public key:

# Create test file in current directory:
Set-Content -Path .\research_doc.txt -Value "Confidential lab report data for Lab 5"

# Encrypt file (Generates .\research_doc.txt.gpg):
gpg --encrypt --recipient "Lab Tester" .\research_doc.txt

# Decrypt test:
gpg --decrypt .\research_doc.txt.gpg
3

Step 3: Detached Digital Signature & Verification (PowerShell)

Generate an ASCII-armored detached signature and verify file integrity:

# Create detached signature (.asc file):
gpg --detach-sign --armor .\research_doc.txt

# Verify signature against the original document:
gpg --verify .\research_doc.txt.asc .\research_doc.txt
